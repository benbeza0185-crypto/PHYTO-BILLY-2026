Global Plant Explorer

Search scientific plant records using common or scientific names. Results come from GBIF's global biodiversity catalogue. Millions of records are searchable, but not every record has a photo or a complete care profile.

Tip: enter a common name or scientific name. Search results may include synonyms and different accepted-name records.

Connection status

No USB device connected.

USB serial works in compatible browsers such as desktop Chrome or Edge on supported operating systems. It may not work on every phone or browser. The website must be opened over HTTPS or localhost.

ESP32 example: send a reading to your server

#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASSWORD";
const char* endpoint = "https://YOUR-SERVER/api/device-data";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  int soil = analogRead(34);

  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(endpoint);
    http.addHeader("Content-Type", "application/json");
    String body = "{\"device\":\"ESP32\",\"soilRaw\":" + String(soil) + "}";
    http.POST(body);
    http.end();
  }
  delay(30000);
}
Important: a browser cannot magically discover and connect to every internet-connected device. Arduino USB can be selected using Web Serial where supported. ESP32/ESP8266/Raspberry Pi connections require firmware plus a reachable server or gateway. Keep Wi-Fi passwords and API keys out of this public HTML file.
