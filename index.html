Hardware integration centre

Connect your devices

Choose your hardware to see how it can communicate with PHYTO-NET. A browser button cannot automatically connect every board; each device needs compatible firmware and a supported connection method.

🔌

Arduino UNO / Mega

Connect by USB serial using a supported desktop browser. The board must send readable serial data.

Not connected
📶

ESP32

Use built-in Wi-Fi to send sensor readings to your secure server using HTTPS or MQTT.

📡

ESP8266

Wi-Fi microcontroller for sending sensor readings to a backend service.

🖥️

Raspberry Pi

Can act as a local gateway, run Python services or manage an MQTT broker.

📱

Bluetooth devices

Bluetooth support varies by board, browser and device. A gateway may be needed.

⚙️

Other IoT boards

Other boards may connect through USB serial, Wi-Fi, HTTP(S), MQTT or a gateway.

USB Serial generally requires a supported Chromium browser such as desktop Chrome or Edge and a secure page (HTTPS or localhost). Never connect wet hardware or expose live electrical parts. Use a separate correctly rated supply for pumps; do not power a pump directly from an Arduino I/O pin.

Example ESP32 data format

Your ESP32 firmware can send a JSON object like this to your backend. This example does not connect until you configure the server and firmware.

{
  "device": "PHYTO-NET-ESP32",
  "plants": {
    "A": {"soilMoisture": 65, "temperature": 24, "humidity": 55},
    "B": {"soilMoisture": 20, "temperature": 25, "humidity": 48},
    "C": {"soilMoisture": 15, "temperature": 26, "humidity": 45}
  }
}
The innovation project

PHYTO-BILLY-2026

Phyto-Net Autonomous Cyber-Clinic is a student innovation project exploring how plant knowledge, sensors and connected technology could support responsible plant care.

The idea combines a plant information website with a physical smart-care prototype built around a microcontroller.

About the creator

Building technology for plant life

Created as a school innovation project by a Senior 1 student in Rwanda. The project aims to make plant learning more accessible and demonstrate how simple electronics can support agriculture.

Mission: connect plant science, practical learning and affordable technology.

Vision: develop a useful platform that can grow through careful testing, research and improvement.

Project status: concept and website interface. Hardware, AI and cloud connections should only be described as operational after they have been assembled, tested and verified.
