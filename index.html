How the connection works

PHYTO-NET device architecture

Step 1: A sensor measures soil moisture, temperature or humidity.

Step 2: A controller such as Arduino UNO or ESP32 reads the sensor.

Step 3: A communication method sends the readings to a secure server.

Step 4: The server stores the information and makes it available to PHYTO-NET.

Step 5: The website displays the readings on the device dashboard.

Example: ESP32 sending data to a server

This is a template. Replace the server address with your own backend endpoint before testing.

#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";
const char* server = "https://YOUR-SERVER.example/api/sensors";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
}

void loop() {
  int moisture = analogRead(34);

  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(server);
    http.addHeader("Content-Type", "application/json");

    String data = "{\"device\":\"ESP32\","
                  "\"soilMoisture\":" + String(moisture) + "}";

    int result = http.POST(data);
    http.end();
  }

  delay(30000);
}
Never put passwords, private API keys or secret server credentials in public code. Use a secure backend, authentication and HTTPS. Arduino UNO generally needs an additional communication device for internet access. ESP32 and ESP8266 have Wi-Fi, but still need a server to connect to this public website.
